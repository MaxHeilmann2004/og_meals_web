# OG Meals

An unofficial meal-planning app created by an Otto Group employee for other employees. OG Meals presents canteen data from official Otto Group services in a mobile-friendly, independently prepared interface.

OG Meals is a private project. It is neither operated nor commissioned by the Otto Group.

## Requirements

- Node.js 24 (see `.node-version`)
- pnpm 11.22.0

## Setup

Install dependencies:

```bash
pnpm install
```

Start the development server at `http://localhost:3000`:

```bash
pnpm dev
```

## Production

Create a production build:

```bash
pnpm build
```

Preview it locally:

```bash
pnpm preview
```

## Testing

Run unit and component tests:

```bash
pnpm test
```

Run ESLint:

```bash
pnpm lint
```

Run the TypeScript checks:

```bash
pnpm typecheck
pnpm typecheck:tests
```

Run functional browser tests:

```bash
pnpm test:e2e
```

Run linting, TypeScript checks, unit/component tests, and the production build with:

```bash
pnpm check
```

The production server entry point generated by Nuxt is:

```bash
node .output/server/index.mjs
```

## Configuration

Set `NUXT_VERIFICATION_TOKEN` to the private access code required to open the meal plan. The verification code can be entered on the site or supplied once as `?verification=<code>`; the server validates the query token before rendering, stores it in an HttpOnly, same-site cookie, then redirects to a clean URL. The code is never exposed in public Nuxt runtime configuration. If the token is not set, access remains closed.

The Nuxt server protects its API proxy and forwards the verified code in the `X-Verification-Code` header. The upstream API must validate this header before direct API access is protected; until that backend change is deployed, the Nuxt site gate does not prevent direct requests to the upstream API.

The following public environment variables are also supported:

```bash
NUXT_PUBLIC_TURNSTILE_SITE_KEY=
NUXT_PUBLIC_PLAUSIBLE_DOMAIN=
```

Plausible events are sent to the self-hosted instance at `https://insights.matix-media.net`.
