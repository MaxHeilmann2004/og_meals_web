# OG Meals

An unofficial meal-planning app created by an Otto Group employee for other employees. OG Meals presents canteen data from official Otto Group services in a mobile-friendly, independently prepared interface.

OG Meals is a private project. It is neither operated nor commissioned by the Otto Group.

## Requirements

- Node.js 24 (see `.node-version`)
- pnpm 11.22.0

## Setup

Install dependencies:

```bash
pnpm install
```

Start the development server at `http://localhost:3000`:

```bash
pnpm dev
```

## Production

Create a production build:

```bash
pnpm build
```

Preview it locally:

```bash
pnpm preview
```

The production server entry point generated by Nuxt is:

```bash
node .output/server/index.mjs
```

## Configuration

The following public environment variables are supported:

```bash
NUXT_PUBLIC_TURNSTILE_SITE_KEY=
NUXT_PUBLIC_PLAUSIBLE_DOMAIN=
```

Plausible events are sent to the self-hosted instance at `https://insights.matix-media.net`.
